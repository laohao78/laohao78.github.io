## 本科时光：培养更广阔的视野

**赵松**：您本科时候就是学霸吗？学习方式是怎样的？

**高飞**：我本科期间绝对算得上是"学霸"，因为大学期间我一直都在努力学习。我一直都很清楚努力的重要性，越长大越觉得要努力，还总觉得自己努力得不够。从大一开始，我就养成了规律的学习习惯：周一到周六，我几乎每天都会泡在图书馆或自习室里（当然偶尔也会看武侠小说放松），周日会在寝室和室友开黑打游戏。

不过，我学习的目的从来不是为了单纯地刷高 GPA，而是真正地去理解知识的本质。比如学微积分的时候，把课本上的所有习题都做了一遍，为的就是把知识学透。到了大三，就开始在实验室"卷"，一边帮老师做课题，一边学习。其实相比于考试，我更喜欢以 project 形式的课程考核，会把课程的 project 当作论文来写，并且很认真地去做。

**赵松**：您对未来想在机器人行业深耕的本科生有什么建议？

**高飞**：首先，一定要好好学习，尤其是要打好数理基础。像微积分、常微分方程、复变函数、概率论这些数学课，我觉得是比较底层和深刻的。我本科数学就挺好的，我不靠死记硬背，而是真的理解和记住了，我想用到的时候能迅速地 recall，如果光顾着刷 GPA，学过了可能就忘了。

其次，本科的时候要有更广阔的视野，相比于在某一个工程技能上精细雕琢，更广泛的知识面、对行业的认知和系统思维更重要。有些本科生问我，本科期间是否要花时间 coding 或做机械设计，我不太建议。等研究生确定方向后，若有需要，花半年时间学习，进步会很快。作为老师，我更看重学生潜力，招学生进来不是让他们单纯写代码、做基础机械工作的。即便本科写了很多代码，也达不到专业从业者的水平，所以本科不必过于焦虑这些具体工程技能。

<span class="insight">高飞的核心教育观：本科拼的不是技能树，是数理地基和行业视野。工程技能半年就能补上，数学思维的差距补起来是以年为单位的。</span>

## 博士岁月：注定孤独地探索前进的路

**赵松**：您博士期间 14 篇论文 0 拒稿，非常厉害。2017 年您在知乎上写的一段话引发了众多读博人的共鸣，能否分享一下？

**高飞**：我在读博时发的那条知乎动态，是当时真实心境的写照。我在香港读博，文化和生活上都不太适应，那边课题组规模较小，组里每个人研究方向都很独立，多数时候我都是独自钻研，压力巨大，还缺乏讨论交流的伙伴。

博士期间我遇到了两个瓶颈：第一个瓶颈是成为合格的博士生。博士第一年既幸福又艰难，幸福在于学习新知识有明显进步，艰难在于不确定所学是否有用，还要面对论文发表和毕业的压力，这种不确定性让人恐惧。不过发表第一篇论文后，我就有了信心。

第二个瓶颈是成为 senior 博士生。我想突破舒适区，做出更有影响力的成果，这个过程很痛苦，但我坚持下来了。整个读博过程孤独且常伴有挫败感，但每一次突破都带来强烈的成就感，这些成就感远胜于科研过程中的痛苦。

读博期间发表 14 篇论文未被拒稿，后来在组里都成了传说。要是谁论文老被拒，大家还会开玩笑说看看能不能和我合作，当然，我们实验室不会随意挂名（笑）。

**赵松**：能详细讲讲您第一篇论文从 idea 到实验落地的过程吗？

**高飞**：博一课程多，压力大，但我一心想做科研，经常熬夜。第一年过年我没回家，忙着准备 PQE 考试，考完就琢磨研究方向。起初尝试了好几个方向都不理想，甚至开始怀疑自己的科研方法。

直到博一第二学期的复活节（香港春假），很多同学都回家或出去玩了，我一个人留在实验室，思索出一个小 idea，实验后感觉可行。假期结束我告知老师，老师让我着手实现，当晚我就行动，第二天便完成初步成果。之后就是设计实验、搭建飞机实验平台，做了大量工程工作，将仿真初步验证转化为能在飞机上运行的代码。

第一篇论文撰写难度很大，不仅考验英语水平，更重要的是逻辑思维。投稿时还出了个小乌龙，我记错提交视频的截止日期，导师提醒我才发现。当时欧洲杯正热播，我一边看球赛一边熬夜剪视频，最后顺利完成投稿，论文还获得一个小会议的 best paper。

<span class="insight">很多人的"第一篇论文困境"不是能力问题，是没熬过那段"尝试好多个方向都不理想"的隧道期。高飞的做法是趁别人放假的时候一个人留在实验室死磕。不是浪漫的灵感迸发——是复活节假期 + 熬夜看球剪视频。</span>

**赵松**：如何快速确定一个 idea 是否可行？

**高飞**：要形成自己的一套快速验证的工具链和验证方法。我刚读博的时候也摸索了这个过程，稳定下来后真的受益很多。有想法后，不能想着一下子全验证，因为一个想法往往很复杂，全部验证耗时太久，大家的关注度和热情都会减退。

我一般会构建一个最小系统去验证，比如我有个关于 planning 或者 control 算法的 idea，不会马上用 ROS 包或者写很长时间的 C++ 代码，而是先在 MATLAB 里写脚本，很快就能有初步结果。如果结果和预期一样，再做下一步。而且在验证的时候，要把决定这个想法能否成功的关键因素抽象出来，在快速开发的工具环境里去验证。

**赵松**：您认为机器人领域优秀的博士生应该具备哪些能力？

**高飞**：我觉得博士毕业理论上应该是能独当一面开展科研课题的初级研究人员。一个优秀的博士生，对自己的小领域要非常熟悉，比如知道领域内现在存在什么问题、过去几年经典问题及解决方法、有哪些研究方法和思路、同行中哪些人最专业、厉害的实验室有哪些及其特点、学科是怎么发展起来的，还有未来独立开展科研可能的路线等。归根结底，就是要具备独立开展科研的能力。

**赵松**：对于没有科研传承条件的学生，独立开展科研有什么好方法？

**高飞**：首先，不要太悲观，每个导师其实都有传承，只是可能和你现在做的东西不相关。每个课题组都有擅长的领域，也会开辟新赛道，这是正常的。而且事物都有两面性，实验室积累少，但行业方向可能不成熟，反而有更多发挥空间。

在实践上，现在学习资源很方便获取，网上有很多公开课和学习资料，可以积极学习基础知识。还可以积极寻求交流的机会，如果自己实验室在某个方向积累不深，可以去外面交流、实习，比如去别的课题组或者大企业，学习别人的经验，也能把自己的想法带过去。

<span class="insight">"实验室积累少"换个角度看就是"没被框死"。高飞把科研传承弱这件事翻转了——不是劣势，是自由度。但前提是你要主动出去交流，不能坐在实验室里抱怨。</span>

## 实验室招生：看重可塑性

**赵松**：您的实验室在业内广为人知，筛选学生的标准是什么？

**高飞**：这个标准其实有点主观，有时候也看缘分。我比较看重学生的可塑性，不太喜欢那种经历特别丰富的学生。比如本科发过很多论文或者拿过很多竞赛奖的，我反而觉得不太靠谱，可能他们受到了不太正确的科研引导和训练，我得花精力帮他们"忘掉"一些东西。这种学生我一般会先 pass 掉。

我更希望学生能在某个方面有独特打动我的点，比如对某个问题有自己独特的见解。去年我招的一个硕士生，他给我发邮件，讲了他对机器人审美和写论文审美的看法，我觉得挺有意思，当场就给了他 offer。

当然，学生能证明自己数理基础扎实很重要，但也不用过分追求高分，90 分和 95 分、99 分其实区别不大，成绩专业第一名和第十名也没有本质区别，我更看重学生后面的想法、决心，以及和我的契合度。

<span class="insight">这条可能会让很多卷竞赛和论文的本科生不舒服。但高飞说的不是"经历没用"——是"被错误引导的经历比没经历更糟"——得花时间让这种学生先"忘掉"错误的东西。空白的可塑性反而更稀缺。</span>

**赵松**：博士期间是应该厚积薄发，还是发几篇文章满足毕业要求就行？

**高飞**：我觉得大家没必要把所有风险和未来的不确定性都压在自己身上，不用非要在博士期间憋出一个完美、轰动世界的东西。刚入门可以先从简单的论文开始，找一个能改进的点，做出成果，合乎逻辑、有效果，通过仿真或实验证明，就是科研成果，**发在普通刊物上也不丢人**。但不能一直停留在简单阶段，要给自己更高要求，不断进步。

我对博士生的毕业要求是一篇长文（全长的期刊论文，十几页的那种）和一篇短文（会议论文），但这只是基本要求，我更看重学生的成长和综合表现。如果学生做的课题很难，5 年没发论文，但写出了非常漂亮的博士论文，我觉得也可以毕业；如果方向发展好，能发很多论文，那也很好。

<span class="insight">"发在普通刊物上也不丢人"——这句可能是全场最解压的话。一个 14 篇顶会 0 拒稿的人说这个，分量不同。他打破了那个"不发顶会就等于白读"的焦虑叙事。</span>

## 预见未来：当有高远的追求

**赵松**：成立微分智飞背后的思考是什么？

**高飞**：我的想法很朴素，我们公司做自主飞行、面向行业的无人机。我就是想尝试做一些国家社会需要的产品，以前是科研成果被产业公司借鉴，现在我想自己把科研成果落地，这样路径更短，也能为行业做更直接的贡献。

**赵松**：从技术角度看，空中机器人现在哪些方面比较成熟，哪些还需要攻克？

**高飞**：我觉得空中机器人的控制方面做得比较成熟了，相比于人形、四足机器人，它的控制更简单，现在行业里在控制方面没有太大问题，也不太值得投入更多资源研发。但在其他层面还有很多要攻克的地方。随着低空经济发展，如果未来天上飞行器很多，它们需要像自动驾驶汽车一样，有很强的应对各种极端情况、遵守规则和避障的能力，比如躲避鸟、气球、建筑物、脚手架、广告牌等非合作目标。而且涉及多机、集群之间的协同，以及个体间的认知任务理解、决策等更抽象的问题，在学术界都还没有很深入的研究。

**赵松**：您怎么看待低空经济发展？哪些场景会率先落地？

**高飞**：我长期看好低空经济，地面空间有限，人类肯定会利用天上的空域，不管是载物还是载人，这都是早晚的事。我觉得物流场景会率先落地，因为它相对技术难度较小，政策和大家的接受度要求也相对低一些，而且物流的体量很大。

**赵松**：基于强化学习的方法在学术圈有很多论文，但实际应用落地的难点在哪？

**高飞**：这方面我也在探索。基于强化学习方法在实际应用落地时，需要很多技巧，包括训练方式、调参方式、数据集构建，还有仿真到实物的迁移以及实物到仿真的迁移。在实物到仿真迁移时，要先测定实物的条件，并导入到仿真中作为模型的一部分。

在具体落地方面，如果只是做实验室 demo，把这些细节处理好，借鉴一些先进经验是可行的。但要做到产品级别，据我所知，业界在无人机领域还没有很好地实现，所以这方面还需要更多的探索和研究。

**赵松**：您怎么看事件相机现在的应用？

**高飞**：我觉得事件相机还是很有前途的。目前它还算比较蓝海的领域，以后很有希望给行业带来变革。现在事件相机存在价格贵、重量大的问题，但它能给机器人带来新的能力，就像火车刚出现时没马车跑得快，但后来火车取代了马车。现在试验相机的发展可能比较慢，不过可研究的问题很多。

**赵松**：现在无人机集群的技术发展到什么阶段了？

**高飞**：无人机集群现在还有很多问题没解决。比如说可靠的分布式、低成本的通讯，超大规模集群的规划，以及在恶劣条件下没有外部信标的相对定位。我们做过十几架无人机的集群实验，靠互相检测和 UWB 互相测距，在这种情况下基本可行，但数量再多一些，局部就可能出现运动退化、遮挡干扰等问题，定位就不太可靠了。

另外，在集群的任务配合方面，现在研究大多集中在运动层面，比如怎么运动得更好、避障更好、保持队形更好，但在认知层面、任务决策方面做得还比较少。像让 100 架飞机去盖一个房子，怎么拆解工序让飞机自动完成任务，这里面有很多逻辑问题值得研究。

**赵松**：传统方法对做端到端或其他新方法有什么帮助？

**高飞**：传统方法能让我们对研究对象更了解，在做端到端训练的时候，就不是盲目地训练和调参。就像控制里的反馈控制和前馈控制，很多人用 PID 控制，但如果有系统模型，加一个前馈就能补偿很多控制误差，让反馈调节的负担变小。传统方法就起到了类似前馈的作用，是很有意义的。

**赵松**：这个是您 2016 年发在知乎上未完成的回答，2025 年的现在是否能给出您的解答了？

**高飞**：我觉得现在的我还很初级，还有很大的成长空间。但如果非要回答这个问题，我觉得有几个原因。第一个是我做事比较喜欢专注，能屏蔽很多干扰，不会让自己变得浮躁，喜欢静下心来做事。第二个是遇到问题我不退缩，我会清楚地认识到自己的害怕，但会强迫自己不害怕，去做更难的选择，走更难的路。第三个是保持乐观，有勇气克服困难，自然就会变得乐观。我从小就爱读名人传记，像毛主席的事迹，总能让我学到很多。另外，我觉得看金庸小说对我也有影响，真正的"大侠"应当拥有广阔的格局和高远的追求，不能将目光仅仅局限于个人的利益得失，要为社会、国家、民族考虑，实现自己更大的人生价值。

<span class="insight">三个原因——专注、不退缩、乐观——听起来像鸡汤。但说的人是 30 岁拿国家优青、博士 14 篇 0 拒稿的人。关键不在于这三个词本身，在于他十年如一日地做到了。"强迫自己不害怕，去做更难的选择，走更难的路"——这句话的反面是：大多数人在害怕那一刻，选了看起来更安全的路。</span>

---

高飞说"发普通刊物也不丢人"，但他是以 14 篇顶会 0 拒稿的身份说的。秦通说 VINS 是站在前人肩膀上，但 5100+ 颗星挂在他名下。

这两个人都在做同一件事：把光环拆开，让你看到里面是一根接力棒、一段孤独的隧道、许多次"强迫自己不害怕"的选择。

与优秀的人同行，不是仰望。是看清楚他们走过的路之后，决定自己也往前走一段。
