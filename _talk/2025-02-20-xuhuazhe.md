## 个人成长：从视觉到机器人的直觉转向

**赵松**：为何从计算机视觉转向机器人方向？

**许华哲**：我是直觉型人格，转向并非深思熟虑的结果。本科接触计算机视觉后，发现能做动作的机器人比纯视觉系统更有趣。受 AlphaGo 和强化学习浪潮影响，决定将博士研究方向锁定在机器人与 RL，目标是创造能决策的智能体。

<span class="insight">"直觉型人格"——这个说法很少在学术访谈里听到。不是 SWOT 分析、不是趋势研判，就是觉得"能动的东西更有趣"。有时候最正确的方向判断来自最不理性的理由。</span>

**赵松**：对本科和低年级硕士有什么建议？

**许华哲**：宏观能力三条——

1. **爱折腾**：为目标不断试错。
2. **对万物去魅**：别神话他人，找到自身优势。
3. **反经验主义**：前辈经验具有时代局限性，需结合当下事实独立判断。

微观能力两条——

1. **工程能力**：机器人领域算法只占一部分，需具备扎实的工程落地能力，比如 3D 打印、焊接。
2. **数学基础**：线性代数和概率论是 AI + Robotics 的基石。

<span class="insight">"对万物去魅"——清华姚班的助理教授跟你说别神话别人。这话从他嘴里说出来比从任何人嘴里说出来都有分量。因为他就站在那个最容易被神话的位置上。</span>

**赵松**：你的招生标准是什么？

**许华哲**：四条——

1. **有抱负**：有想做一番事业的内驱力，不管是创业还是科研。
2. **自驱力强**：我喜欢松弛管理，学生需能自我驱动。
3. **生存能力**：具备在社会上立足的能力，包括社交、开源、代码。
4. **落地执行力**：通过 Project 考察在规定时间内扎实完成项目的能力。

## 技术洞察：具身智能的架构与瓶颈

**赵松**：具身智能技术栈与自动驾驶有什么异同？

**许华哲**：架构自底向上分为六层——

1. 核心零部件：电机、结构件
2. 整机设计：机械工程师主导的重心与耐久度设计
3. 系统集成：感知与运动控制模块接入
4. ROS 层：机器人的"神经系统"
5. 软件智能：传统控制 + 基于模仿/强化学习的智能模块
6. 大脑规划：任务分解与规划

核心差异：具身智能操作精度要求极高，比如抓取容错空间仅 1cm，且需外接数据采集与遥操作系统。

**赵松**：产业链薄弱环节在哪里？

**许华哲**：智能部分，尤其是数据稀缺。多模态大模型方案成熟，但数据采集成本高、效率低，严重制约发展。

<span class="insight">六层架构里，硬件和整机不是瓶颈，ROS 层已经很成熟。卡在最上面两层——软件智能和大脑规划。而这两层的共同瓶颈是数据。数据采集成本不降下来，具身智能就走不出实验室。</span>

**赵松**：人形机器人是必然吗？

**许华哲**：具身智能不限于人形，但人形是通用性最强的形态，因为它适配人类环境。目前应用场景仍在探索中，工厂重复劳动、商超服务是潜在方向。

**赵松**：终局是"一脑多形"还是"一脑一形"？

**许华哲**：**"一脑多形"是终局。** 初期因算法弱而"一脑一形"，但数据天然稀缺决定了必须整合不同形态数据训练通用模型，底层物理语义可相互借鉴。

<span class="insight">这条判断和硅基文明第三篇里讲的完全一致——"硅基生命的形态和认知是分离的"。许华哲从技术角度给出了同样的答案：数据稀缺倒逼"一脑多形"。</span>

## 落地挑战：安全、伦理与多学科融合

**赵松**：具身智能的安全伦理挑战和自动驾驶相比呢？

**许华哲**：相似点是都涉及责任归属，比如养老机器人出事谁负责。不同点在于，自动驾驶是集中式高风险（高速场景），具身智能是分散式小风险（多场景、操作精度问题）。目前行业多聚焦单一任务如搬箱、整理，伦理讨论较少。

**赵松**：CS、EE、机械等多学科如何融合？

**许华哲**：决胜点在 AI，但缺一不可。硬件、软件、数据必须协同。创始团队虽无纯硬件背景，但通过对外销售本体证明了系统完整性的重要性。最终方向是交叉融合。

## 学习路线：具身智能入门书单

**赵松**：转行/入门有什么建议与课程推荐？

**许华哲**：至少懂 ROS，尽量有硬件实践，训练到部署的完整流程最能提升能力。

必看课程清单——

| 领域 | 课程 | 重点 |
|---|---|---|
| 机器人基础 | Modern Robotics（西北大学） | 正逆运动学、动力学 |
| AI 基础 | CS188（Berkeley） | 搜索、滤波（粒子滤波/卡尔曼） |
| 机器学习 | CS229（Stanford） | 理论体系，**必做作业** |
| 深度学习/CV | CS231N（Stanford） | 手写反向传播，基本网络结构 |
| 深度强化学习 | CS285（Berkeley, Sergey Levine） | 具身智能核心，机器人案例多 |
| 机器人进阶 | CS287（Berkeley, Pieter Abbeel） | Learning + Control 融合 |
| 机器人操作 | Manipulation（MIT, Russ Tedrake） | 专注操作任务 |

实践：复现 Diffusion Policy 等开源项目。

<span class="insight">这份书单的价值不在课程本身——这些课网上都能搜到。在于是他说的：CS229 "必做作业"，CS231N "手写反向传播"。很多人刷课只看了视频。他说的"学"是真的动手做。</span>

## 行业预判：泡沫中的生存法则

**赵松**：模仿学习与强化学习的进展如何？

**许华哲**：模仿学习借 Transformer 和扩散模型复兴，仍在改进中。强化学习经历 DQN 高潮后因数据效率低陷入低谷，现在因为 ETH 等机构在真实世界的工作重现希望。

**赵松**：有落地价值的研究方向是什么？

**许华哲**：做能提升数据效率或具有规模化效应的事。比如——

1. 用 RL 对齐大模型解决空间智能
2. 真实世界交互学习

避免在仿真里做无法迁移的小应用。

**赵松**：投资泡沫怎么看？未来两到三年会洗牌吗？

**许华哲**：肯定有泡沫。关键在于能否在泡沫破裂前产生实际价值——不管是劳动力价值还是情绪价值。洗牌后，能进工厂、商超落地的团队将存活。

<span class="insight">他没用"泡沫会破"来吓唬人，也没说"泡沫没关系"。他说的是：泡沫是肯定的，你唯一能做的事是在它破之前做出真东西。劳动力价值和情绪价值——这两个词很实在。机器人要么替人干活，要么让人觉得有个机器人陪着挺好。</span>

---

三场访谈下来，秦通讲接力棒，高飞讲不丢人，许华哲讲去魅。

三个人，三个方向，一条暗线：**把光环拆掉，把路看清楚。**

秦通拆的是开源神话——一个项目背后是三个人的接力。高飞拆的是科研焦虑——发普通刊物也可以，别非得憋一篇轰动世界的。许华哲拆的是权威崇拜——别神话别人，包括他自己。

与优秀的人同行，不是让你模仿他们的履历。是让你看到，他们走过的路不是魔法铺的。是接力棒、是复活节假期一个人死磕、是"强迫自己不害怕"的选择。普通人也有机会走。
