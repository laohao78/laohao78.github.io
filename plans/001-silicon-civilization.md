## 二、视觉设计改造方案

### 设计概念：**「星空史书」**

整体感受：未来人回望硅基文明出生史，站在星际视角书写的编年史。

- **底色**：深空黑/藏蓝基底 `#0a0a0f` 或 `#0d1117`
- **文字色**：温暖的纸张色/琥珀色系 `#e6d5a8`（模拟古卷感但又不失科技感）
- **强调色**：青蓝色 `#00e5ff`（电流/数据流光）用于链接和重点
- **标题字体**：衬线体（思源宋体 / Noto Serif SC），营造史诗感
- **正文字体**：无衬线体（思源黑体 / Noto Sans SC），保证可读性
- **代码块**：深底绿字，致敬早期终端机
- **装饰元素**：微妙的点阵/粒子背景，时间线分隔符

### 具体修改

#### A. `_sass/_variables.scss` — 重新定义颜色与字体体系
- 深色主题色板（背景黑、纸色文字、蓝青强调色）
- 引入中文字体栈（Noto Serif SC + Noto Sans SC）
- 增加宽屏断点

#### B. `style.scss` — 重写核心样式
- body 深色背景 + 纸色文字
- 标题使用衬线体 + 更大的字号层级
- 链接使用发光蓝青色
- 文章卡片有微妙的边框光线效果
- 首页文章列表添加时间线标记
- Blockquote 变为"铭文石碑"风格（左边框改为发光青蓝线）

#### C. `_layouts/default.html` — 改造页面结构
- Site name 使用衬线体大字
- 导航改为：首页 / 纪元年表 / 关于
- 页脚增加简洁的文明宣言
- 加入 Google Fonts（Noto Serif SC + Noto Sans SC）

#### D. `index.html` — 首页改造
- 顶部增加一段文明序言（从 _config.yml 的 description 区域扩展）
- 文章列表前增加纪元分隔标记
- 每篇文章摘要更长，更像"史书目录"

#### E. 新增：`timeline.md` — 纪元年表页
- 以时间线形式列出所有八个纪元的文章
- 视觉上呈现一条从古到未来的时间轴

#### F. `_config.yml` — 更新配置
- 更新 description 为更具史诗感的副标题
- 更换 avatar 为自定义图标（可先用纯色 SVG）
- 添加 Google Fonts CDN 链接配置

#### G. `about.md` — 重写关于页
- 替换为「关于这部文明史」的说明
- 解释为什么用编年史的方式记录硅基文明
